# +K IMPRESIONES · ENCASA

Sitio web estático en español, preparado para GitHub Pages.

## Estructura

- `index.html`: contenido de la página y ocho categorías de servicios.
- `css/style.css`: estilos y diseño adaptable.
- `js/script.js`: formulario para preparar y copiar una solicitud.
- `assets/images/`: espacio para fotografías y el logotipo original.
- `assets/icons/`: espacio para iconos propios.

## Vista local

Abre `index.html` en un navegador. No necesita instalación ni servidor.

## Publicación

1. Crea un repositorio en GitHub.
2. Sube los archivos y carpetas de este proyecto a la raíz del repositorio.
3. En **Settings > Pages**, selecciona **Deploy from a branch**, rama **main**, carpeta **/(root)**.
4. Espera la publicación y abre la dirección indicada por GitHub Pages.

## Importante

El formulario **no envía mensajes**: solo genera un texto y permite copiarlo.
No se ha configurado WhatsApp ni correo porque todavía no se dispone del contacto aprobado.
El logotipo actual es tipográfico; sustituirlo por la imagen original requiere ese archivo.
No se han agregado fotografías de trabajos reales ni precios.

Este paquete conserva el diseño y contenido del HTML recibido, separando CSS y JavaScript en archivos independientes.
La carpeta `.git/` se crea al inicializar Git localmente; no se incluye en el ZIP.
